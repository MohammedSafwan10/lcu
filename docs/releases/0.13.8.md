# LCU 0.13.8

**`lcu prune` reports the space it actually frees.**

## Changes

- **`lcu prune`: sizes no longer include the ChatGPT app.** On macOS each release links the app in `/Applications`, and prune's size count followed that link, so every release was reported at the app's size (about 2.1 GiB) instead of its own (about 36 MiB). Removal was not affected: it deletes the link, never the app. The count now includes links themselves and never what they point at.

## Upgrading

Run `lcu update`. To go back, reinstall 0.13.7.
