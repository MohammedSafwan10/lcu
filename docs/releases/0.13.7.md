# LCU 0.13.7

**Computer-use approvals in T3 Code now offer Allow this conversation and Always allow.**

## Changes

- **Claude Code in T3 Code: approvals ask once per conversation.** T3 Code runs Claude Code through the Agent SDK (`CLAUDE_CODE_ENTRYPOINT=t3-code`) with no surface the `lcu-approve` mod can draw a pane in, so the mod used to leave the app approval to T3 Code's own card. That card's Approve reached the runtime as Allow once, so the same app was asked about again on later calls, and T3 Code's "Always allow this session" was kept only by T3 Code, not by the runtime. The mod now asks with the question card, as it already does in the Claude app: Allow this conversation, Always allow (when the runtime offers it) and Deny. The choice goes to the runtime, so a conversation grant shows in `/computer-use-apps` and Always allow needs no `lcu apps allow`. Checked live in T3 Code 0.1.7 on macOS arm64. The Claude app and the terminal are unchanged.

## Upgrading

Run `lcu update`, which refreshes the `lcu-approve` mod. A running T3 Code session picks the change up without a restart. To go back, reinstall 0.13.6.
